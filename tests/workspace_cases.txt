# Cases for the workspace module, read by both of its versions: tests/workspace_test.lua (the mpv plugin's,
# mpv/scripts/workspace/workspace.lua) and `cargo test` (gyroflow-export's, vs-gyroflow/src/workspace.rs).
#
# case <name>      a new case: an empty folder (a temporary one; the Lua test fakes it), which is also the home folder
# home <dir>       the home folder is <dir> in it instead
# tree             then one path per line, indented, made in it: a folder ends with /, else it's an empty file
# clip <path>      then, indented, what's expected for that clip:
#   project <dir>    the project it belongs to (- for none)
#   relative <path>  its path in that project
#   new <dir>        where a project for it would be made
#   gyroflow <file>  its Gyroflow project (- for none)
#   gyroflow-new <file>  where a new one is written
#   sidecar <file>   where its own file is (its marks and view)
# volume <unix|windows> <path> <yes|no>   whether the path is a volume's top folder (no tree: plain strings)
#
# Paths are relative to the case's folder and use /.

case a project in the trip folder
tree

  Egypt/Day 1/DJI_0068_D.gyroflow
