Download · the latest release

Download Action Footage Player

Free and open source. The app for your Mac or PC carries everything it needs: nothing else to install, no account.

Early alpha Files served from GitHub GPL-3.0

Action Footage Player is a desktop app. Open this page on your Mac or PC to download it.

macOS

Your system

Apple Silicon (M1 or later), macOS 15 Sequoia or later

Download for Mac .dmg

Installing on macOS

  1. Open the download and drag both apps, ActionFootagePlayer and ActionFootageLibrary, onto Applications.
  2. Open it. The first time, macOS won't: the app is signed ad hoc, not by an Apple developer account. Open System Settings → Privacy & Security, scroll down to Security, click Open Anyway next to ActionFootagePlayer and confirm.
  3. Accept its setup: it becomes the player for MP4 videos (macOS asks you to confirm), Finder gets the Quick Actions Play Stabilized and Stabilize + LUT, and DJI's Rec.709 LUT is downloaded from DJI.

It carries its own mpv and ffmpeg. To update, replace it in Applications with the new version. No build for Intel Macs.

Windows

Your system

Windows 10 or 11 on Intel or AMD (x86-64), DirectX 12 or Vulkan graphics

Download for Windows .exe

Installing on Windows

  1. Run the installer. It needs no admin rights: it installs for you alone, in %LOCALAPPDATA%\Programs\ActionFootagePlayer. If your browser says the file isn't commonly downloaded, choose Keep.
  2. The installer isn't signed, so the first time Windows SmartScreen warns about it: click More info, then Run anyway.
  3. It puts ActionFootagePlayer in Open With for MP4 and MOV videos, with Play in ActionFootagePlayer and Stabilize + LUT in Explorer's menu (on Windows 11 under Show more options). It downloads DJI's Rec.709 LUT and, if you leave it ticked, opens Settings to make it the default app for MP4 videos.

It carries its own mpv, VapourSynth with its Python, and ffmpeg. Uninstall it from Settings → Apps.

Linux

Your system

x86-64, with an mpv of your own. No app for Linux yet

The plugins

Installing on Linux

No app for Linux yet: the plugins go into the mpv you already have. Or, from a checkout of the source, ./install.sh builds and installs them all, with DJI's LUT; ./install.sh --apps also puts ActionFootagePlayer in the applications menu as the default app for MP4 videos.

The stabilization, distribution by distribution

  • Fedora 44 and later yesFor HEVC and H.264, RPM Fusion's ffmpeg: sudo dnf swap ffmpeg-free ffmpeg --allowerasing
  • Fedora 43 yesmpv 0.40: no right-click menu. ffmpeg as above
  • openSUSE Tumbleweed yesFor HEVC and H.264, Packman's ffmpeg
  • Flathub's mpv untriedIt has VapourSynth, but its sandbox hides the system's ffmpeg, and exports can go only to Videos, Pictures and /tmp
  • Arch Linux, EndeavourOS noIts mpv 0.41.0 is built without it: mpv's fix for the current VapourSynth isn't released yet. An mpv built from git has it
  • Debian, Ubuntu, Linux Mint, Pop!_OS noNeither VapourSynth nor an mpv with it in their archives. Building both yourself (mpv from git) can work, but it takes an evening and hasn’t been tried here. The other plugins work
  • Snap's mpv noBuilt without VapourSynth
  • ARM (aarch64) noThe stabilization is built for x86-64 only

As checked on 3 November 2026. On any of them, mpv --vf=help | grep vapoursynth tells whether your mpv has it. The other plugins need only mpv, the right-click menu 0.41 or later.

Built by every release, not yet tried on Linux by hand.

Already use mpv?

The plugins alone

The same plugins the app carries, for your own mpv, all in one zip: D-Log M and other log curves in HDR, DJI telemetry on screen, the highlights the camera marked, the right-click menu (mpv 0.41 or later), and stabilization with export, built for each system. Nothing goes in mpv.conf or input.conf.

macOS

Your system

Homebrew's mpv on Apple Silicon

Download the plugins .zip

The plugins on macOS

  1. Install mpv, and ffmpeg for exports, with Homebrew: brew install mpv ffmpeg.
  2. Unzip it into mpv's scripts folder: unzip mpv-plugins-*.zip -d ~/.config/mpv/scripts. Unzipped in Finder, it's a folder: move the folders in it to ~/.config/mpv/scripts/.
  3. Downloaded with a browser, the stabilization's binaries carry the quarantine flag, and macOS refuses them: xattr -dr com.apple.quarantine ~/.config/mpv/scripts/gyroflow

D-Log M plays in HDR: DJI's Rec.709 LUT isn't redistributed. Adding it, and the rest in detail

Windows

Your system

mpv built with VapourSynth, x86-64

Download the plugins .zip

The plugins on Windows

  1. Unzip it into mpv's scripts folder, %APPDATA%\mpv\scripts\ (make the folder if there's none).
  2. For the stabilization: an mpv built with VapourSynth (mpv --vf=help lists vapoursynth; shinchiro's builds have it), VapourSynth itself with its Python, and graphics with DirectX 12 or Vulkan.
  3. For exports: ffmpeg in PATH, or ffmpeg.exe and ffprobe.exe copied next to gyroflow-export.exe.

The other plugins need only mpv. The app has all of it in it. Linux and Windows, in detail

Your footage on a NAS?

NAS Helper

A Docker container for a NAS with an x86-64 processor and an Intel GPU, next to your projects. It keeps a project’s catalog current from the NAS’s side, so what one computer changes shows on the others at once. It streams every clip and moment stabilized and in HDR, as the player shows them, to a browser, a phone or a TV. And, if you turn it on, it puts your moments, your clips or both in a Jellyfin library. It’s for people at ease with Docker: every setting is described.

Linux, Docker

A NAS with an x86-64 processor and an Intel GPU (VA-API), Docker. Built on a UGREEN DXP with an N100

Download the NAS Helper .tar.gz

Installing the NAS Helper

  1. Copy the download to the NAS and load it over SSH: docker load -i ActionFootageNASHelper-*-linux-x86_64.tar.gz.
  2. Take the example compose file and change its folders to the NAS’s: each project twice (read-write for the guardian, read-only for the stream), the shares its footage is on, and two folders of the helper’s own.
  3. Start it: docker compose up -d, or as a project in the NAS’s Docker app. Its log says what it found and runs; http://<nas>:8099/settings shows every setting with what it does.

The example compose file · Every setting, in detail

Alpha: used on one NAS so far. Links for Jellyfin are off until you turn them on.
