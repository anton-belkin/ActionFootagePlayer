Install

  1. Unzip the download and move ActionFootagePlayer to Applications.
  2. Open it. The first time, macOS won't: the app is signed ad hoc, not by an Apple developer account. Open System Settings → Privacy & Security, scroll down to Security, click Open Anyway next to ActionFootagePlayer and confirm.
  3. Accept its setup: it becomes the player for MP4 videos (macOS asks you to confirm), Finder gets the Quick Actions Play Stabilized and Stabilize + LUT, and DJI's Rec.709 LUT is downloaded from DJI.

It carries its own mpv and ffmpeg. To update, replace it in Applications with the new version. No build for Intel Macs.

Install

  1. Run the installer. It needs no admin rights: it installs for you alone, in %LOCALAPPDATA%\Programs\ActionFootagePlayer. If your browser says the file isn't commonly downloaded, choose Keep.
  2. The installer isn't signed, so the first time Windows SmartScreen warns about it: click More info, then Run anyway.
  3. It puts ActionFootagePlayer in Open With for MP4 and MOV videos, with Play in ActionFootagePlayer and Stabilize + LUT in Explorer's menu (on Windows 11 under Show more options). It downloads DJI's Rec.709 LUT and, if you leave it ticked, opens Settings to make it the default app for MP4 videos.

It carries its own mpv, VapourSynth with its Python, and ffmpeg. Uninstall it from Settings → Apps. No build for Windows on ARM.

Linux

Your system

x86-64, with an mpv of your own

The plugins for your mpv

No app for Linux yet: the plugins go into the mpv you already have. Or, from a checkout of the source, ./install.sh builds and installs them all, with DJI's LUT; ./install.sh --apps also puts ActionFootagePlayer in the applications menu as the default app for MP4 videos.

Built by every release, not yet tried on Linux by hand.

Already use mpv?

The plugins alone

The same plugins the app carries, for your own mpv. Unzip them into mpv's scripts folder: ~/.config/mpv/scripts/, or %APPDATA%\mpv\scripts\ on Windows. Nothing goes in mpv.conf or input.conf.

Stabilization on Linux and Windows

It needs an mpv built with VapourSynth (mpv --vf=help lists vapoursynth; on Windows, shinchiro's builds have it, Debian's and Ubuntu's mpv doesn't), VapourSynth itself with its Python, a GPU with Vulkan (or DirectX 12 on Windows), and ffmpeg for exports. Put mpv-dlogm next to it for D-Log M.

Stabilization on macOS

Downloaded with a browser, its binaries carry the quarantine flag and macOS refuses them. Once it's unzipped: xattr -dr com.apple.quarantine ~/.config/mpv/scripts/gyroflow

Plugins in your own mpv

From source

On a Mac, ActionFootagePlayer-<version>-macos-arm64.tar.gz is the source with the binaries prebuilt, so ./install.sh --apps needs no Rust. From a plain checkout it builds them (Rust, 5–10 minutes the first time).
