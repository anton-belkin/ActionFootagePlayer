macOS

Votre système

Apple Silicon (M1 ou plus récent), macOS 15 Sequoia ou ultérieur

Télécharger pour Mac .dmg

Installer sur macOS

  1. Ouvrez le fichier téléchargé et faites glisser ActionFootagePlayer sur Applications.
  2. Ouvrez-la. La première fois, macOS refuse de l’ouvrir : l’app est signée ad hoc, et non par un compte développeur Apple. Ouvrez Réglages Système → Confidentialité et sécurité, faites défiler jusqu’à la rubrique Sécurité, cliquez sur Ouvrir quand même à côté d’ActionFootagePlayer et confirmez.
  3. Acceptez sa configuration : elle devient le lecteur des vidéos MP4 (macOS vous demande de confirmer), le Finder reçoit les actions rapides Play Stabilized et Stabilize + LUT, et la LUT Rec.709 de DJI est téléchargée depuis le site de DJI.

Elle embarque ses propres mpv et ffmpeg. Pour la mettre à jour, remplacez-la dans Applications par la nouvelle version. Pas de version pour les Mac Intel.

Windows

Votre système

Windows 10 ou 11 sur Intel ou AMD (x86-64), carte graphique DirectX 12 ou Vulkan

Télécharger pour Windows .exe

Installer sur Windows

  1. Lancez le programme d’installation. Il ne demande aucun droit d’administrateur : il installe l’app pour vous seul, dans %LOCALAPPDATA%\Programs\ActionFootagePlayer. Si votre navigateur signale que ce fichier n’est pas téléchargé fréquemment, choisissez Conserver.
  2. Le programme d’installation n’est pas signé : la première fois, Windows SmartScreen affiche un avertissement. Cliquez sur Informations complémentaires, puis sur Exécuter quand même.
  3. Il ajoute ActionFootagePlayer à « Ouvrir avec » pour les vidéos MP4 et MOV, avec Play in ActionFootagePlayer et Stabilize + LUT dans le menu de l’Explorateur de fichiers (sous Windows 11, dans « Afficher d’autres options »). Il télécharge la LUT Rec.709 de DJI et, si vous laissez la case cochée, ouvre les Paramètres pour en faire l’app par défaut des vidéos MP4.

Elle embarque ses propres mpv, VapourSynth avec son Python, et ffmpeg. Pour la désinstaller : Paramètres → Applications.

Linux

Votre système

x86-64, avec votre propre mpv. Pas encore d’app pour Linux

Les plugins

Installer sur Linux

Pas encore d’app pour Linux : les plugins s’installent dans le mpv que vous avez déjà. Ou bien, depuis une copie du code source, ./install.sh les compile et les installe tous, avec la LUT de DJI ; ./install.sh --apps ajoute aussi ActionFootagePlayer au menu des applications, comme app par défaut des vidéos MP4.

La stabilisation, distribution par distribution

  • Fedora 44 et ultérieures ouiPour le HEVC et le H.264, le ffmpeg de RPM Fusion : sudo dnf swap ffmpeg-free ffmpeg --allowerasing
  • Fedora 43 ouimpv 0.40 : pas de menu du clic droit. ffmpeg comme ci-dessus
  • openSUSE Tumbleweed ouiPour le HEVC et le H.264, le ffmpeg de Packman
  • Le mpv de Flathub pas essayéIl inclut VapourSynth, mais son bac à sable cache le ffmpeg du système, et les exports ne peuvent aller que dans Vidéos, Images et /tmp
  • Arch Linux, EndeavourOS nonSon mpv 0.41.0 est compilé sans : le correctif de mpv pour le VapourSynth actuel n’est pas encore publié. Un mpv compilé depuis git l’a
  • Debian, Ubuntu, Linux Mint, Pop!_OS nonNi VapourSynth ni un mpv qui l’inclut dans leurs dépôts. Les compiler soi-même (mpv depuis git) peut marcher, mais c’est une soirée de travail, pas encore essayée ici. Les autres plugins fonctionnent
  • Le mpv de Snap nonCompilé sans VapourSynth
  • ARM (aarch64) nonLa stabilisation n’est compilée que pour x86-64

Vérifié le 3 novembre 2026. Partout, mpv --vf=help | grep vapoursynth indique si votre mpv l’a. Les autres plugins n’ont besoin que de mpv, le menu du clic droit de mpv 0.41 ou ultérieur.

Compilés à chaque version, mais pas encore essayés à la main sous Linux.

Vous utilisez déjà mpv ?

Les plugins seuls

Les mêmes plugins que ceux de l’app, pour votre propre mpv, tous dans un seul zip : le D-Log M et les autres courbes log en HDR, la télémétrie DJI à l’écran, les temps forts marqués par la caméra, le menu du clic droit (mpv 0.41 ou ultérieur), et la stabilisation avec l’export, compilée pour chaque système. Rien à ajouter dans mpv.conf ni dans input.conf.

macOS

Votre système

Le mpv de Homebrew sur Apple Silicon

Télécharger les plugins .zip

Les plugins sous macOS

  1. Installez mpv, et ffmpeg pour les exports, avec Homebrew : brew install mpv ffmpeg.
  2. Décompressez-le dans le dossier scripts de mpv : unzip mpv-plugins-*.zip -d ~/.config/mpv/scripts. Décompressé dans le Finder, c’est un dossier : déplacez les cinq dossiers qu’il contient dans ~/.config/mpv/scripts/.
  3. Téléchargés avec un navigateur, les binaires de la stabilisation portent l’attribut de quarantaine, et macOS refuse de les lancer : xattr -dr com.apple.quarantine ~/.config/mpv/scripts/gyroflow

Le D-Log M s’affiche en HDR : la LUT Rec.709 de DJI n’est pas redistribuée. L’ajouter, et le reste en détail

Télécharger les plugins .zip

Les plugins sous Windows

  1. Décompressez-le dans le dossier scripts de mpv, %APPDATA%\mpv\scripts\ (créez le dossier s’il n’existe pas).
  2. Pour la stabilisation : un mpv compilé avec VapourSynth (mpv --vf=help affiche vapoursynth ; les builds de shinchiro l’incluent), VapourSynth lui-même avec son Python, et une carte graphique DirectX 12 ou Vulkan.
  3. Pour les exports : ffmpeg dans le PATH, ou ffmpeg.exe et ffprobe.exe copiés à côté de gyroflow-export.exe.
