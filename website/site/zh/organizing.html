整理素材

你的素材自成一个项目，不管它放在哪里。

把一次旅行中最好的部分留成精彩瞬间，标出重要的地方，并按相机、地点或标签找到任何片段，无论它在这台电脑上还是在你的 NAS 上。随播放器附带的应用 Action Footage Library 能看到全部素材，并在你观看的同时在后台处理它们。

  • 观看从不等于保存。打开、观看片段不会往里面写入任何东西。只有你为此按下按键或按钮时，播放器才会写入。

项目

素材在哪里，你做出的东西放到哪里。

项目说明两件事。一是你的原始片段在哪里：任意文件夹，在这台电脑上或 NAS 上。二是你用它们做出的东西放在哪里：精彩瞬间在 _Moments，片段预览在 _Clips，导出的文件在 _Exports，照片在 _Stills。

它的文件 Project.afproject 只保存这些：素材所在的文件夹，称为它的位置（locations）。其他一切都在文件本身里。精彩瞬间里带着它的片段的身份，照片也一样；片段的标记和保存的画面设置，在片段旁边的一个小文件里。所以项目跟着素材走：把整个文件夹，连同素材和项目一起，复制到另一块硬盘或 NAS 上，一切照常运作。

每次旅行一个项目，或者所有素材一个项目：两种都行。原始文件从不被改动，它们可以留在相机 Wi-Fi 上传或你的 NAS 放它们的地方。

创建项目

播放器从不自行创建项目。你第一次保存精彩瞬间或导出时，侧边面板会打开到 Project（项目）标签页，显示 No project yet（还没有项目）。从列表中选择文件夹，列表从片段所在的文件夹一直到磁盘的最上层，然后按 Initialize the project here（在此初始化项目）。其中的每个文件夹都属于这个项目，更多位置可以在 Library 中添加。双击 Project.afproject，就在 Action Footage Library 中打开它。

项目自己的文件可以和素材分开存放，比如放在快速的 SSD 上，而片段留在 NAS 的大硬盘上：Library 的 Move the project（移动项目）会把 Project.afproject 和项目的文件夹搬到那里，原来的文件夹则成为一个位置。

标记不需要项目：它们反正都保存在片段旁边。

文件

一切都是你看得见的文件。

经过几次旅行之后的一个项目：它自己的文件夹在 SSD 上，素材在 NAS 上。项目的文件夹以下划线开头，所以排在最前面。

右边的大小说明了一切：原始文件和导出的文件很大，精彩瞬间和片段的翻页预览很小。留几百个也没关系，复制到哪里都行。

播放器和 Library 生成的东西，会放进对应类别文件夹里的 Generated 文件夹。从那里，你可以把它移到项目中的任何地方、重命名它、建你自己的文件夹：它仍然能被找到，因为每个文件里都带着它的链接。删掉一个精彩瞬间的文件，这个精彩瞬间就没了。

项目文件旁边是 .afp，也就是共享目录：Library 对这些文件所知道的信息，让它打开得很快。它可以删除：会根据文件重新建立。

Action Footage Library

整个项目，在一个独立的应用里。

对单个片段做的事，在播放器里完成。对许多片段做的事，在 Action Footage Library 里完成，它是随播放器附带的应用。它把项目按文件夹浏览，按片段本身的特点找到它们，并在后台一个接一个地执行你要求的任务，你可以同时继续观看。

浏览

顶部有五个视图：Originals（原始文件），即各个位置在磁盘上的原样；Footage（素材），即按你在 _Clips 中整理预览的方式排列的片段；以及 Moments、Photos 和 Exports。双击打开文件夹，就像在访达文件资源管理器中一样，可以用图片网格或列表显示。片段会在播放器中打开。

筛选和搜索

Filters（筛选）缩小你所在文件夹的范围：按相机、按色彩（Log、HDR 或 SDR）、按片段有没有运动数据或是否为 360°、按标记和精彩瞬间、标签、渲染，以及录制地点，每一项都显示有多少个匹配。在搜索框中输入，就会在下方列出所有匹配，或者在整个视图中搜索。

对所选内容执行命令

选择方式和访达文件资源管理器一样：单击、⌘Ctrl+单击、Shift+单击，选中文件夹就是选中其中的一切。右侧的 Commands（命令）只作用于所选内容，不涉及其他：片段预览、标记的精彩瞬间和照片、渲染、导出、Stabilize optically、检查、标签、位置。

任务和信息

Tasks（任务）列出正在运行和等待中的任务，每项都显示进度、正在处理的内容和 Stop（停止）；无法生成的内容会连同原因一起列出。任务运行期间，Mac 不会进入睡眠。Info（信息）说明你选中的内容：片段的日期、时长、相机、镜头配置文件和地点，或者一个文件夹的汇总。

打开方式：在播放器的 Project 标签页中点 Open in Action Footage Library，或者双击 Project.afproject。它不用自己的代码生成任何东西：每项任务都是在没有窗口的情况下运行播放器，所以一切产出都和播放器生成的完全一样。

在 Mac 上，它在下载包里，就在播放器旁边Windows 上，它随播放器一起安装，在开始菜单中有自己的条目。在 Linux 上，播放器目前一次处理一个片段，Library 正在路上。

位置

素材分在几块硬盘上，仍是一个项目。

相机上传到 NAS 上快速的收件文件夹，片段之后再移到归档，你要剪辑的那些在 SSD 上留一份副本。项目把它们看作一棵文件夹树。

位置

在项目的设置中，Locations（位置）列出素材所在的文件夹，每个都放在项目的文件夹树中：放在最上层，或者作为其中的一个文件夹（比如把收件文件夹放成 Action 6/）。它们以网络路径的形式写下，所以每台电脑都能找到。片段取自第一个拥有它的位置，所以 SSD 上的副本会代替归档中的那一份播放。

从访达文件资源管理器也能找到

保存位置时，会在每个位置的最上层留下一个小文件 <project>.afplocation，这样你双击的片段能找到它的项目、它的精彩瞬间和它的标记。被移出的位置会失去这个文件；其中的其他东西都不变。

并入另一个项目

在笔记本电脑上做的一次旅行，拷到了 NAS 上？Take in another project…（并入另一个项目）会把它的精彩瞬间、预览、照片和导出的文件一次性并入这个项目，并在它的素材还不在这个项目之内时，添加它的位置。然后它的 Project.afproject 会移到废纸篓回收站。开始之前，它会列出将要做的事。

检查

对所选内容执行 Check（检查），会告诉你哪里有问题：原始文件丢失、精彩瞬间找不到它的片段、同一个片段出现两次、一个片段有两个自己的文件。Find moved files（查找移动过的文件）会在项目的各个位置中寻找丢失的文件并修复链接，无法判断时会问你。

链接

跟着文件走的链接。

精彩瞬间、片段预览、照片和导出的文件，都按片段本身是什么来认出它：它的大小、相机写在里面的时间，以及它内容的指纹。它原来在哪里只是一个线索。所以素材移到了另一个文件夹或位置，或者被重命名，仍然保持链接：链接会重新找到它，并记下它的新位置。

你自己的文件也是这样被找到的：靠它们里面的链接，放在项目的任何文件夹里都行。精彩瞬间和预览随你怎么整理。

在项目的设置中，I never rename my footage（我从不重命名素材）让移动过的片段也能按名称找到，这在大型归档上更快。

目录

共享目录，让它打开得很快。

Library 把它对项目文件所知道的信息保存在项目旁边的 .afp 中。NAS 上一个有几千个片段的项目，从任何一台电脑上都能瞬间打开：第一次打开它的电脑读取目录，而不是逐个查看每个文件。

播放器和 Library 做的任何事，都会立刻显示在视图中：保存的精彩瞬间、任务生成的文件、一个标签。在访达文件资源管理器中所做的改动，会在 Library 下次查看这些文件夹时显示出来，几分钟之内。文件始终是准绳：目录只是上次看到它们时的样子。

在哪里，用什么

每个片段在哪里录制，用的是哪个镜头。

地点，来自你的照片

运动相机很少记录它在哪里。你的手机记录了：选中片段，在 Library 的 Location（地点）中按 Suggest from Apple Photos（根据 Apple 照片建议），时间上最接近的带地点的照片就会给出建议。每条建议都显示它们在时间上相差多少；合适的你就留下。照片只会被读取，从不被改动；Mac 会请你允许一次，让 Library 读取它。相机录下了 GPS 的片段已经有地点了。也可以手动设置：像地图复制出来的那样填写纬度和经度，喜欢的话再加上潜点的名称。

地点会写进每个原始文件自己的那个文件，就在它旁边，所以它跟着片段走。Info 显示地点的名称，在一张小地图上，Location 筛选按国家、地区和地点找到片段。

Info 中的镜头配置文件

防抖需要镜头的配置文件。片段上的 Info 会说明播放器用的是哪一个：相机写在文件里的那个，或者 Gyroflow 数据库中针对这台相机和这个模式评分最高的那个。还没有合适的配置文件时，它会显示相机的模式编号，把它告诉我们，就能把配置文件加进来。

  • 根据 Apple 照片给出的建议只在 Mac 上有。在 Windows 上，请手动设置地点。
  • 按片段的时钟对应。相机记时间的方式各不相同：DJI、Insta360 和较新的 GoPro 用世界协调时间，较老的 GoPro 用当地时间。Library 按每台相机的方式读取，所以它比较的照片来自正确的那个小时。

缩略图

每个片段都有一张缩略图，和访达文件资源管理器画出来的一样快。

Library 向系统要它自己的缩略图，在 Mac 上是快速查看的在 Windows 上是文件资源管理器的：NAS 上的 300 个片段，第一次 9 秒就显示出来，之后不到一秒。然后，要让整次旅行都是彩色的，还有片段预览。

Make clip previews

Log 素材（一种保留更多光线信息的录制模式，在转换之前看起来又平又灰）是一整墙灰色图标。选中片段或文件夹，Make clip previews（生成片段预览）会为每个还没有预览的片段生成一个小 MP4：由片段中带标记的帧组成的翻页预览，或者由均匀分布在片段中的约 12 帧组成，都是彩色的。一次一个，在后台进行。

随你怎么排列

它们放在 _Clips/Generated 中：as the footage's folders（按素材的文件夹）、by trips（按旅行，相隔不超过 2 天的片段放在一起），或者 all in one folder（全部放在一个文件夹里）。在访达的图标视图中，整个旅程都是彩色的；快速查看（空格键）几秒钟就能翻完一个片段。在大图标视图中，整个旅程都是彩色的。在播放器中打开一个预览，播放的是整个片段。

整理它们

它们就是文件：复制、整理进你自己的文件夹、随意重命名都可以。每一个都始终链接到它的原始片段，Library 的 Footage 视图会按你排列的样子显示这些片段。

把片段放到一边

在播放器中，X 把片段的预览移到废纸篓回收站：“Not interesting”（不感兴趣）。片段本身不动。再按一次 X 会重新生成预览；对于还没有预览的片段，Project 标签页的 Make this clip's preview（生成此片段的预览）只生成这一个。

Stabilize optically

片段里没有运动数据？没关系。

播放器根据相机随片段一起记录的运动来稳定画面。DJI 相机只有在它的防抖（EIS）关闭时才记录运动数据，有些相机则根本不记录。对于这些片段，Gyroflow 会从画面本身找出运动。

选中片段或它们所在的文件夹，按 Stabilize optically（光学防抖）。Gyroflow 从每个片段的画面中测出它的运动，在后台一个接一个地进行，所需时间大约与片段的播放时长相当（4K 60 fps 时再多一半）。它的项目放在每个片段旁边，从此播放器就会像对待其他片段一样稳定地播放它。

Lens（镜头）为这些片段选择镜头：每个片段自己的，即相机录下的那个；或者在相机有多种镜头类型时选一种（Osmo Action 6：Wide 或 Normal）。它与每个片段一起保存，播放器也会用它。选了镜头，或按 Redo（重做），会重新生成这些片段的 Gyroflow 项目，保留它们的设置。

不需要的片段会被排除，并列出原因：播放器能用上运动数据的、已经有 Gyroflow 项目的、360° 片段，以及镜头还未知的片段。

它使用 Gyroflow 的命令行光学分析，这项功能正在进入 Gyroflow 的官方版本。在那之前，它需要用我们的分支构建的 Gyroflow。在播放器中一次处理一个片段，任何版本的 Gyroflow 都可以：Ctrl+e，见防抖。

标签和渲染

用来查找的词语，以及提前做好的精彩瞬间。

标签

给片段、精彩瞬间、预览、照片和导出的文件加上任意词语：海豚、给家人、最佳。命令中的 Tags（标签）在所选内容上添加和移除标签；筛选和搜索都能找到它们。标签与它的条目保存在一起：在片段自己的文件里，在精彩瞬间或预览内部的链接里，以及照片的元数据里，Apple 照片和 Lightroom 会把它读作关键词。

渲染

在 Moments 中，Render（渲染）把选中的精彩瞬间做成成品视频，HDR、SDR 或两者都要，在后台进行，放进 _Renders。每个渲染都知道自己是由什么做成的：修改了精彩瞬间，它就会显示为过期；再按一次 Render 只重做改变了的部分。同一风格的导出会直接复制一份最新的渲染，而不是再渲染一遍。删掉渲染不会破坏任何东西。

所有标记的精彩瞬间和照片

在选中的片段上：Moments of the marks（标记的精彩瞬间）为每个还不在精彩瞬间里的标记生成一个精彩瞬间，前后各 2 秒，以发生的时间命名。Photos of the marks（标记的照片）在每个标记处保存一张照片，可以是静态照片、Live Photo 或 Motion Photo。

导出

在 Moments 中，Export（导出）为每个选中的精彩瞬间生成一个视频，各自按自己的设置，就像 Shift+E 导出单个一样：按播放器显示的样子导出为 HDR，或者导出为 SDR。已经以该风格导出过的会被跳过。

在播放器中：标记

先是相机的精彩时刻，然后是你自己的标记。

标记是片段中的一个时间点。录制时按过精彩时刻按键？这些标记已经在视频下方的导航栏上了，显示为琥珀色的菱形：DJI Osmo Action 4、Action 5 Pro 或 Action 6 上的快捷切换按键或遥控器，GoPro HERO5 及更新机型上的 HiLight。你的标记是白色的。指向其中一个，导航栏会显示它的名称和精确到百分之一秒的时间；点一下就跳到它所在的那一帧。Ctrl+] 和 Ctrl+[，或者导航栏上的箭头，跳到下一个和上一个。

M 在视频当前位置添加一个标记。在标记上（半秒以内）按 M 则删除它，相机的标记也一样。

第一次改动会在片段旁边写入 <clip>.afp.json，并把相机的标记复制进去。从此以后，这个文件就是片段的标记。片段保存的画面设置也放在这里：也就是你在侧边面板的 Source（源）和 Transform（变换）标签页中用 Save to the source（保存到源）保存的内容，这样片段打开时就是你保存的样子。删掉这个文件，相机的精彩时刻就恢复原样，保存的画面设置也会被忘掉。片段本身从不被写入。

标记不需要项目。在侧边面板中，Marks of this clip（此片段的标记）列出它们：相机的标记显示为 “DJI quick switch” 或 “GoPro HiLight”，你的显示为 “Mark 3”。点一下就跳过去。

在播放器中：精彩瞬间

精彩瞬间是一个小文件。打开它，播放的是原始文件。

在一段的开头按 l，结尾再按 l，然后按 k，输入一个名称。

名称

播放器会问 “Moment 0:20–0:30 name (Enter: Turtle 2):”。只按 Enter 就采用建议的名称：你上一次用的名称加上下一个编号；如果你还没输入过任何名称，则是拍摄的日期和时间。Tab 把建议放进输入框供你修改，↑ 调出之前用过的名称，Esc 不保存任何东西。

文件

它成为 _Moments/Generated 中的 Turtle.afplink.mp4：一个小 MP4，显示这一段中的一帧彩色画面（其中的第一个标记，否则是中间那一帧），里面有指向原始文件的链接。访达和快速查看文件资源管理器显示的就是这一帧。它的文件日期是拍摄的时间，所以按日期排序时，精彩瞬间会按发生的先后排列。

播放它

在播放器中打开时，它以完整画质播放原始文件中的这一段，然后是文件夹里的下一个精彩瞬间。从 NAS 上播放也只要几秒钟：一个 2.5 GB 片段中的精彩瞬间 3 到 5 秒就能显示，因为播放器先读取它要播放的那一段的运动数据，其余的边播边读。打开一个精彩瞬间文件夹本身，其中所有精彩瞬间都会按发生的先后播放。双击时也是这样，前提是 Action Footage Player 是打开 MP4 文件的 App（显示简介 → 打开方式 → 全部更改…）；否则系统播放的是只有一帧的预览。

删掉文件，就删掉了精彩瞬间

没有需要同步维护的列表。重命名它、移进你自己的文件夹、给它加标签：它仍然是一个精彩瞬间。在侧边面板中，Moments of this clip（此片段的精彩瞬间）有 Rename… 和 Remove，后者把它移到废纸篓回收站。

修改它的首尾

播放这个精彩瞬间，用 l 移动它的开头或结尾，然后按 k。播放器会问 “Update Turtle to …? Enter, or a new name for a new one”（把 Turtle 更新为……？按 Enter，或输入新名称另存一个）。它的访达标签保持不变。

按保存时的样子观看

精彩瞬间是完整保存下来的，取自你按 k 时正在播放的样子：它的防抖、强度、地平线、镜头、色差校正、时域降噪和画幅。如果片段有 Gyroflow 项目，精彩瞬间会得到它自己的一份副本，裁短到这一段。精彩瞬间从不自行改变：之后修改片段或片段的项目，都不会影响它。片段如何读取（它的 Log 曲线、它的旋转、水下的镜头）仍属于片段本身，对它所有的精彩瞬间都适用。

精彩瞬间播放时，侧边面板的 Transform 标签页会显示 Transform defined in（变换定义于）the moment（精彩瞬间）。改动任何设置都只用于观看，除非打开了 Auto save：“Changed for viewing. The dot marks what's saved”（仅为观看而改动，圆点标出已保存的设置）。Save to the moment（保存到精彩瞬间）会写入它，Revert to saved（恢复为已保存）则恢复原样。关闭 Settings of its own（自己的设置），精彩瞬间就按它的片段保存的方式播放；它自己的设置和它的 Gyroflow 副本都会去掉，副本移到废纸篓回收站。

在播放器中：导出

导出的文件放在 _Exports，带有指回原始文件的链接。

Shift+E 按播放的样子导出标记的一段或整个片段：画面稳定，色彩正常。它像精彩瞬间一样询问名称，如果这一段本身就是精彩瞬间，则建议用它的名称：“Export 0:20–0:30 (SDR) as (Enter: Turtle):”。导出进行中再按一次 Shift+E 即可取消。

文件是 _Exports/Turtle.mov。不带括号的名称是 HDR（在能显示的屏幕上有明亮的高光）；其他风格会注明：Turtle (SDR).mov、Turtle (Dolby Vision).mov。每个导出的文件都带有指向原始文件的链接。还不是精彩瞬间的一段，也会同时保存为一个精彩瞬间 export_Turtle，这样你可以删掉导出的文件腾出空间，以后仍能以完整画质播放这一段。

侧边面板的 Output（输出）标签页在 Export（导出）下也有同样的功能：Export the part 或 Export the clip、Export in SDR、Show the last export。要一次导出许多精彩瞬间，请用 Action Footage Library。各种风格和格式见 Log 素材页面。

在播放器中：剪掉

剪掉在口袋里拍下的那一分钟。

用 l 和 l 标出拍坏的一段，按 Ctrl+x，然后确认。片段会被重写，去掉这一段，且不重新编码：保留的每一帧都原样复制。不需要项目。

播放器会先询问：“Cut 0:05–0:20 out of DJI_20261024094541_0093_D.MP4? Kept: 0:00–0:05 and 0:20–end (two clips; the second from the keyframe at or before 0:20), without re-encoding. The original goes to the Trash.”（从片段中剪掉 0:05–0:20？保留 0:00–0:05 和 0:20 至结尾，成为两个片段，第二个从 0:20 处或之前的关键帧开始，不重新编码。原始文件移到废纸篓。）选择 Cut it out（剪掉）或 Keep the clip as it is（保留片段原样）。

保留什么

  • 剪掉中间的一段，会留下两个片段。第一个保留原始文件的名称。第二个以它自己的录制时间命名，例如 DJI_20261024094600_0093_D.MP4。
  • 第二个片段从剪切终点处或之前的关键帧（其他帧赖以构建的完整帧）开始，所以拍坏的部分最多可能留下约一秒。
  • 某一侧剩下不到半秒的，会被丢弃。
  • 相机的数据都会保留：镜头、色彩模式、用于防抖的运动数据、时间码、声音。每个新片段在替换任何东西之前都会被读回并核对；如果不一致，就什么都不改。
  • 每个新片段都会得到原始文件保存的画面设置，以及落在它之内的标记和精彩瞬间。完全落在被剪掉部分之内的精彩瞬间，会被移到废纸篓回收站。

改变什么

  • 原始文件会移到废纸篓回收站，连同它的附属文件：.LRF、它的 Gyroflow 项目、它的 .afp.json 和片段预览。在网络共享文件夹或存储卡上没有回收站，所以它们会改为放进项目的 .Trash 文件夹，消息中也会说明。
  • 播放器中无法撤销。你可以手动把原始文件从废纸篓回收站中取回，但第一个新片段现在用的是它的名称。
  • 目前只支持 DJI 的片段。我们正在支持其他相机。在那之前，GoPro 的片段要先通过检查才会剪切，Insta360 和 iPhone 的片段则会被拒绝。
  • 导出的文件不受影响，它们的链接仍然指向原始文件。要为新片段生成片段预览，请按 Make clip previews，它在 Action Footage Library 中。

局限

依赖它之前要知道的事。

  • 精彩瞬间是一个链接。它需要它的原始文件在项目的某个位置中，且未经改动。移动或重命名都没问题；重新编码过的原始文件是另一个文件，它的精彩瞬间会失去它。
  • 精彩瞬间文件不是用来发送的。在别处它只是一帧静止画面，聊天软件和重新编码也会去掉其中的链接。请发送导出的文件。
  • 精彩瞬间的文件只显示一帧，不是这一段的视频。
  • 片段预览没有防抖，它们的帧是最近的关键帧，与标记最多相差约一秒。
  • 标记还不能自己命名：它们叫 “Mark 1”、“Mark 2”，或者沿用相机的名称。
  • 项目需要一个可以写入的文件夹。打开了写保护锁的存储卡：先把它拷到你的硬盘或 NAS 上，再在那里创建项目。
  • 剪切会替换片段。原始文件移到废纸篓回收站，播放器中无法撤销，导出的文件仍指向旧的原始文件，而且这个功能是为 DJI 片段做的。
  • 跟随项目文件夹的 Apple 照片相簿会在以后的版本中推出；目前 Library 读取照片只是为了地点。
  • 在 Linux 上，播放器目前一次处理一个片段。Linux 上还没有 Action Footage Library，所以在那里，一次处理许多片段的任务要等它推出。
  • 在 Windows 上，项目、精彩瞬间、预览和 Action Footage Library 目前测试不多。

常见问题

开始之前。

播放器会修改我的素材吗？

只有在你用 Ctrl+x 剪掉一段并确认时才会：这时片段会被保留下来的部分替换，原始文件移到废纸篓回收站。除此之外，它只读取你的片段。在每个片段旁边，它会在你改动标记、保存片段的画面设置，或者给它设置地点或标签之后，写入一个属于这个片段的小文件 <clip>.afp.json；在你制作 Gyroflow 项目时写入这个项目。其他一切都放在项目的文件夹里。

标记需要项目吗？

不需要。不管有没有项目，标记都保存在片段旁边。精彩瞬间、片段预览、导出、X 和 Action Footage Library 才需要项目。

我把素材移到了 NAS 上。我的精彩瞬间丢了吗？

没有。把新文件夹加到项目的位置中，或者把整个项目文件夹和它一起移动。精彩瞬间按片段本身是什么来找到它，而不只是按它原来在哪里，并记下它的新位置。Library 中的 Check 会显示仍然缺失的东西，Find moved files 会修复它。

所有素材一个项目，还是每次旅行一个？

都可以。所有素材一个项目，Library 就能跨所有旅行搜索和筛选；每次旅行一个项目，就是一个可以整体移动或归档的文件夹。一次旅行的项目以后可以用 Take in another project… 并入一个更大的项目。

可以把精彩瞬间发给朋友吗？

请改为发送导出的文件：在精彩瞬间上按 Shift+E。精彩瞬间自己的文件只是一帧画面，外加一个指向只有你才有的片段的链接。

Library 会改动我的 Apple 照片吗？

不会。它读取你照片的时间和地点，用来建议片段是在哪里录制的，不会改动照片中的任何东西。
