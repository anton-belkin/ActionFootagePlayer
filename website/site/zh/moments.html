精彩瞬间

把最好的几分钟留成看得见的文件。

标记一段，按 k：它就成为一个精彩瞬间，一个放在本次旅行 _Moments 文件夹里的小视频，访达和快速查看文件资源管理器和它的预览窗格都以正常色彩显示它。在播放器里打开它，播放的是原始文件中的那一段，画质完整。第一次使用时，要在侧边面板的 Project 标签页里选好这次旅行的文件夹：Initialize the project here（在此初始化项目）。

你自己的标记

看到了按键漏掉的画面？M 在当前位置加一个标记。在标记上再按 M 则删除它。

放到一边，或加标签

X 把片段标为没意思，放到一边。在 Action Footage Library 中，给片段和精彩瞬间加上词语，比如最佳或给家人，再用它的筛选把它们找回来。

整个旅程一目了然

Action Footage Library 是随播放器附带的应用，它给你所有旅行的每个片段都配上缩略图，并按相机、地点或标签找到它们。它会在 _Clips 文件夹里为每个片段生成一本彩色的翻页小书，而不是一墙灰色缩略图。从侧边面板的 Project 标签页打开它。

常见问题

下载之前，先看看这些。

需要会调色或剪辑吗？

不需要。Log 素材直接以正常色彩播放，标记好的一段按一个键就能导出。如果你确实要调色和剪辑，剪辑软件会拿到原始文件，以及上面的精彩瞬间和标记。

相机上需要设置什么吗？

想要色彩，就用相机的 Log 模式拍摄，不用也行：普通片段照常播放。想要播放时画面稳定，就关掉相机自身的防抖（DJI 的 EIS、GoPro 的 HyperSmooth、Insta360 的 FlowState），这样相机会记录下运动数据，播放器据此稳定画面。DJI 相机只有在使用 Wide 视角时才会记录这些数据。请直接从存储卡复制片段：经过其他应用导出或裁剪的片段，会丢失播放器要读取的信息。

它会修改我的原始文件吗？

只有你要求时才会。要把片段中拍坏的一段剪掉（Ctrl+x），播放器会重写这个片段、去掉那一段，不做任何重新编码，原始文件则移到废纸篓。除此之外，你的原始文件都保持原样：精彩瞬间、片段预览和导出的文件都是独立的新文件，你的标记则是片段旁边的一个小文件。

我的精彩瞬间存在哪里？

_Moments、_Clips 和 _Exports 文件夹放在项目文件夹里，也就是这次旅行的文件夹，你只需在侧边面板的 Project 标签页里选一次（Initialize the project here）。它可以是片段所在的文件夹，也可以是它的上一级文件夹；其他硬盘或 NAS 上的素材，可以在 Action Footage Library 中加进来。写保护的存储卡：先把它拷到你的硬盘或 NAS 上。

Mac 还是 Windows？

每天都在用的是 Mac 版（Apple Silicon）。Windows 版也能用，但还是 Alpha 版，目前测试不多。

免费吗？

是的，以 GPL-3.0 协议开源。不会锁定任何功能，也无需注册账号。
