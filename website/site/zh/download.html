macOS

你的系统

Apple Silicon（M1 或更新），macOS 15 Sequoia 或更高版本

下载 Mac 版 .dmg

在 macOS 上安装

  1. 打开下载的文件，把 ActionFootagePlayer 拖到「应用程序」文件夹。
  2. 打开它。第一次打开时 macOS 会拒绝：这个 App 只有临时（ad hoc）签名，而不是用 Apple 开发者账号签名的。打开系统设置 → 隐私与安全性，向下滚动到「安全性」，点按 ActionFootagePlayer 旁边的仍要打开并确认。
  3. 接受它的初始设置：它会成为 MP4 视频的播放器（macOS 会请你确认），访达会多出两个快速操作 Play Stabilized 和 Stabilize + LUT，并从 DJI 下载 DJI 的 Rec.709 LUT。

它自带 mpv 和 ffmpeg。要更新时，用新版本替换「应用程序」文件夹中的旧版即可。没有适用于 Intel Mac 的版本。

Windows

你的系统

Windows 10 或 11，Intel 或 AMD 处理器（x86-64），显卡需支持 DirectX 12 或 Vulkan

下载 Windows 版 .exe

在 Windows 上安装

  1. 运行安装程序。它不需要管理员权限：只为你一个人安装，位置是 %LOCALAPPDATA%\Programs\ActionFootagePlayer。如果浏览器提示该文件不常被下载，请选择保留。
  2. 安装程序没有签名，所以第一次运行时 Windows SmartScreen 会发出警告：点击更多信息，再点击仍要运行。
  3. 它会把 ActionFootagePlayer 加入 MP4 和 MOV 视频的「打开方式」，并在文件资源管理器的右键菜单中加入 Play in ActionFootagePlayer 和 Stabilize + LUT（Windows 11 上位于「显示更多选项」之下）。它会下载 DJI 的 Rec.709 LUT；如果你保留勾选，还会打开「设置」，让你把它设为 MP4 视频的默认应用。

它自带 mpv、VapourSynth（连同其所需的 Python）和 ffmpeg。可在「设置 → 应用」中卸载。

Linux

你的系统

x86-64，需自备 mpv。暂时还没有 Linux 版 App

插件

在 Linux 上安装

Linux 版 App 暂时还没有：插件直接装进你已有的 mpv。或者在源码的检出目录中运行 ./install.sh，它会构建并安装全部插件，连同 DJI 的 LUT；./install.sh --apps 还会把 ActionFootagePlayer 加入应用程序菜单，并设为 MP4 视频的默认应用。

各发行版上的防抖

  • Fedora 44 及更高版本 支持要播放 HEVC 和 H.264，请换用 RPM Fusion 的 ffmpeg：sudo dnf swap ffmpeg-free ffmpeg --allowerasing
  • Fedora 43 支持mpv 0.40：没有右键菜单。ffmpeg 同上
  • openSUSE Tumbleweed 支持要播放 HEVC 和 H.264，请使用 Packman 的 ffmpeg
  • Flathub 的 mpv 未试过它带有 VapourSynth，但沙盒看不到系统的 ffmpeg，导出也只能写入「视频」「图片」和 /tmp
  • Arch Linux, EndeavourOS 不支持它的 mpv 0.41.0 构建时没有启用：mpv 针对当前 VapourSynth 的修复尚未发布。从 git 构建的 mpv 带有它
  • Debian、Ubuntu、Linux Mint、Pop!_OS 不支持软件源中既没有 VapourSynth，也没有带它的 mpv。自己构建两者（mpv 用 git 版本）也许可行，但要花一个晚上，我们还没试过。其他插件都能用
  • Snap 的 mpv 不支持构建时未启用 VapourSynth
  • ARM（aarch64） 不支持防抖只为 x86-64 构建

核实于 2026 年 11 月 3 日。无论哪个发行版，mpv --vf=help | grep vapoursynth 都能告诉你自己的 mpv 是否带有它。其他插件只需要 mpv，右键菜单需要 0.41 或更高版本。

每次发布都会自动构建，但还没有在 Linux 上亲手试过。

已经在用 mpv？

单独的插件

与 App 自带的插件相同，供你自己的 mpv 使用，全部装在一个 zip 里：以 HDR 显示 D-Log M 及其他 Log 曲线、在屏幕上显示 DJI 遥测数据、相机标记的精彩时刻、右键菜单（mpv 0.41 或更高版本），以及为每个系统构建的防抖和导出。无需改动 mpv.conf 或 input.conf。

macOS

你的系统

Apple Silicon 上用 Homebrew 安装的 mpv

下载插件 .zip

macOS 上的插件

  1. 用 Homebrew 安装 mpv，以及用于导出的 ffmpeg：brew install mpv ffmpeg。
  2. 把它解压到 mpv 的 scripts 文件夹：unzip mpv-plugins-*.zip -d ~/.config/mpv/scripts。在访达中解压会得到一个文件夹：把其中的五个文件夹移到 ~/.config/mpv/scripts/。
  3. 用浏览器下载时，防抖的二进制文件会带上隔离标记，macOS 会拒绝运行它们：xattr -dr com.apple.quarantine ~/.config/mpv/scripts/gyroflow

Windows 上的插件

  1. 把它解压到 mpv 的 scripts 文件夹 %APPDATA%\mpv\scripts\（没有就新建一个）。
  2. 防抖需要：启用 VapourSynth 构建的 mpv（mpv --vf=help 的输出中会列出 vapoursynth；shinchiro 的构建版本带有它）、VapourSynth 本身及其 Python，以及支持 DirectX 12 或 Vulkan 的显卡。
