安装

  1. 解压下载的文件，把 ActionFootagePlayer 移到「应用程序」文件夹。
  2. 打开它。第一次打开时 macOS 会拒绝：这个 App 只有临时（ad hoc）签名，而不是用 Apple 开发者账号签名的。打开系统设置 → 隐私与安全性，向下滚动到「安全性」，点按 ActionFootagePlayer 旁边的仍要打开并确认。
  3. 接受它的初始设置：它会成为 MP4 视频的播放器（macOS 会请你确认），访达会多出两个快速操作 Play Stabilized 和 Stabilize + LUT，并从 DJI 下载 DJI 的 Rec.709 LUT。

它自带 mpv 和 ffmpeg。要更新时，用新版本替换「应用程序」文件夹中的旧版即可。没有适用于 Intel Mac 的版本。

安装

  1. 运行安装程序。它不需要管理员权限：只为你一个人安装，位置是 %LOCALAPPDATA%\Programs\ActionFootagePlayer。如果浏览器提示该文件不常被下载，请选择保留。
  2. 安装程序没有签名，所以第一次运行时 Windows SmartScreen 会发出警告：点击更多信息，再点击仍要运行。
  3. 它会把 ActionFootagePlayer 加入 MP4 和 MOV 视频的「打开方式」，并在文件资源管理器的右键菜单中加入 Play in ActionFootagePlayer 和 Stabilize + LUT（Windows 11 上位于「显示更多选项」之下）。它会下载 DJI 的 Rec.709 LUT；如果你保留勾选，还会打开「设置」，让你把它设为 MP4 视频的默认应用。

它自带 mpv、VapourSynth（连同其所需的 Python）和 ffmpeg。可在「设置 → 应用」中卸载。没有适用于 ARM 版 Windows 的版本。

单独的插件

与 App 自带的插件相同，供你自己的 mpv 使用。把它们解压到 mpv 的 scripts 文件夹：~/.config/mpv/scripts/，Windows 上则是 %APPDATA%\mpv\scripts\。无需改动 mpv.conf 或 input.conf。

Linux 和 Windows 上的防抖

它需要启用 VapourSynth 构建的 mpv（mpv --vf=help 的输出中会列出 vapoursynth；在 Windows 上，shinchiro 的构建版本带有它，Debian 和 Ubuntu 自带的 mpv 则没有）、VapourSynth 本身及其 Python、支持 Vulkan 的 GPU（Windows 上也可以是 DirectX 12），以及用于导出的 ffmpeg。要播放 D-Log M，请把 mpv-dlogm 一并装上。

macOS 上的防抖

用浏览器下载时，其中的二进制文件会带上隔离标记，macOS 会拒绝运行它们。解压之后运行：xattr -dr com.apple.quarantine ~/.config/mpv/scripts/gyroflow

从源码安装

在 Mac 上，ActionFootagePlayer-<version>-macos-arm64.tar.gz 是附带预编译二进制文件的源码，所以 ./install.sh --apps 不需要 Rust。从普通的源码检出安装时，它会自行编译这些文件（需要 Rust，首次约 5–10 分钟）。
