Установка

  1. Распакуйте архив и перенесите ActionFootagePlayer в папку «Программы».
  2. Откройте его. В первый раз macOS не даст этого сделать: приложение подписано ad hoc, а не учётной записью разработчика Apple. Откройте Системные настройки → Конфиденциальность и безопасность, прокрутите вниз до раздела «Безопасность», нажмите Всё равно открыть рядом с ActionFootagePlayer и подтвердите.
  3. Согласитесь на начальную настройку: приложение станет плеером для видео MP4 (macOS попросит это подтвердить), в Finder появятся быстрые действия Play Stabilized и Stabilize + LUT, а LUT Rec.709 от DJI будет скачан с сайта DJI.

Собственные mpv и ffmpeg входят в приложение. Для обновления замените его в папке «Программы» новой версией. Сборки для Mac на Intel нет.

Установка

  1. Запустите установщик. Права администратора ему не нужны: он устанавливает приложение только для вас, в %LOCALAPPDATA%\Programs\ActionFootagePlayer. Если браузер предупредит, что такой файл скачивают редко, выберите Сохранить.
  2. Установщик не подписан, поэтому в первый раз Windows SmartScreen предупредит о нём: нажмите Подробнее, затем Выполнить в любом случае.
  3. Он добавляет ActionFootagePlayer в «Открыть с помощью» для видео MP4 и MOV, а в меню Проводника — пункты Play in ActionFootagePlayer и Stabilize + LUT (в Windows 11 — в разделе «Показать дополнительные параметры»). Он скачивает LUT Rec.709 от DJI и, если не снимать галочку, открывает «Параметры», чтобы вы назначили приложение используемым по умолчанию для видео MP4.

В приложение входят собственные mpv, VapourSynth со своим Python и ffmpeg. Удалить его можно в разделе «Параметры» → «Приложения». Сборки для Windows на ARM нет.

Плагины для вашего mpv

Приложения для Linux пока нет: плагины устанавливаются в mpv, который у вас уже есть. Или, если у вас есть клон исходного кода, ./install.sh соберёт и установит их все вместе с LUT от DJI; ./install.sh --apps вдобавок добавит ActionFootagePlayer в меню приложений как приложение по умолчанию для видео MP4.

Собирается для каждого выпуска, но вручную на Linux ещё не опробовано.

Уже пользуетесь mpv?

Только плагины

Те же плагины, что входят в приложение, — для вашего собственного mpv. Распакуйте их в папку scripts вашего mpv: ~/.config/mpv/scripts/ или %APPDATA%\mpv\scripts\ в Windows. В mpv.conf и input.conf ничего прописывать не нужно.

Стабилизация в Linux и Windows

Нужны mpv, собранный с VapourSynth (mpv --vf=help выводит vapoursynth; в Windows такой mpv есть в сборках shinchiro, а в mpv из Debian и Ubuntu его нет), сам VapourSynth со своим Python, видеокарта с Vulkan (или DirectX 12 в Windows) и ffmpeg для экспорта. Для D-Log M положите рядом mpv-dlogm.

Из исходного кода

На Mac ActionFootagePlayer-<version>-macos-arm64.tar.gz — это исходный код с уже собранными исполняемыми файлами, так что ./install.sh --apps обойдётся без Rust. Из обычного клона репозитория скрипт соберёт их сам (нужен Rust, в первый раз это занимает 5–10 минут).
