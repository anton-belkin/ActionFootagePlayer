Установка на macOS

  1. Откройте загруженный файл и перетащите оба приложения, ActionFootagePlayer и ActionFootageLibrary, в папку «Программы».
  2. Откройте его. В первый раз macOS не даст этого сделать: приложение подписано ad hoc, а не учётной записью разработчика Apple. Откройте Системные настройки → Конфиденциальность и безопасность, прокрутите вниз до раздела «Безопасность», нажмите Всё равно открыть рядом с ActionFootagePlayer и подтвердите.
  3. Согласитесь на начальную настройку: приложение станет плеером для видео MP4 (macOS попросит это подтвердить), в Finder появятся быстрые действия Play Stabilized и Stabilize + LUT, а LUT Rec.709 от DJI будет скачан с сайта DJI.

Собственные mpv и ffmpeg входят в приложение. Для обновления замените его в папке «Программы» новой версией. Сборки для Mac на Intel нет.

Ваша система

Windows 10 или 11 на Intel или AMD (x86-64), видеокарта с DirectX 12 или Vulkan

Скачать для Windows .exe

Установка на Windows

  1. Запустите установщик. Права администратора ему не нужны: он устанавливает приложение только для вас, в %LOCALAPPDATA%\Programs\ActionFootagePlayer. Если браузер предупредит, что такой файл скачивают редко, выберите Сохранить.
  2. Установщик не подписан, поэтому в первый раз Windows SmartScreen предупредит о нём: нажмите Подробнее, затем Выполнить в любом случае.
  3. Он добавляет ActionFootagePlayer в «Открыть с помощью» для видео MP4 и MOV, а в меню Проводника — пункты Play in ActionFootagePlayer и Stabilize + LUT (в Windows 11 — в разделе «Показать дополнительные параметры»). Он скачивает LUT Rec.709 от DJI и, если не снимать галочку, открывает «Параметры», чтобы вы назначили приложение используемым по умолчанию для видео MP4.

В приложение входят собственные mpv, VapourSynth со своим Python и ffmpeg. Удалить его можно в разделе «Параметры» → «Приложения».

Установка на Linux

Приложения для Linux пока нет: плагины устанавливаются в mpv, который у вас уже есть. Или, если у вас есть клон исходного кода, ./install.sh соберёт и установит их все вместе с LUT от DJI; ./install.sh --apps вдобавок добавит ActionFootagePlayer в меню приложений как приложение по умолчанию для видео MP4.

Скачать плагины .zip

Плагины в macOS

  1. Установите mpv и ffmpeg (для экспорта) через Homebrew: brew install mpv ffmpeg.
  2. Распакуйте архив в папку scripts вашего mpv: unzip mpv-plugins-*.zip -d ~/.config/mpv/scripts. Если распаковать его в Finder, получится папка: перенесите папки из неё в ~/.config/mpv/scripts/.
  3. Если скачать архив через браузер, исполняемые файлы стабилизации получают атрибут карантина, и macOS отказывается их запускать: xattr -dr com.apple.quarantine ~/.config/mpv/scripts/gyroflow

Видео лежит на NAS?

NAS Helper

Docker-контейнер для NAS с процессором x86-64 и графикой Intel, рядом с вашими проектами. Он позволяет нескольким людям работать в одной библиотеке вместе: каждый видит изменения других через секунду. Он отдаёт каждый клип и момент стабилизированными и в HDR, как их показывает плеер, — в браузер, на телефон или телевизор. А если включить, кладёт ваши моменты, клипы или и то и другое в Jellyfin, Emby или Kodi. Для тех, кто на «ты» с Docker: каждая настройка описана.

Linux, Docker

NAS с процессором x86-64 и графикой Intel (VA-API), Docker. Собран на UGREEN DXP с N100

Скачать NAS Helper .tar.gz

Установка NAS Helper

  1. Скопируйте файл на NAS и загрузите его по SSH: docker load -i ActionFootageNASHelper-*-linux-x86_64.tar.gz.
  2. Возьмите пример compose-файла и поменяйте в нём папки на папки NAS: каждый проект дважды (на запись — для совместной работы, только на чтение — для стрима), сетевые папки с его видео и две папки для самого помощника.
  3. Запустите: docker compose up -d или проектом в Docker-приложении NAS. В логе видно, что он нашёл и что запустил; http://<nas>:8099/settings показывает каждую настройку и что она делает.

В состав приложения входят mpv и ffmpeg, распространяемые по собственным лицензиям. Проект не связан с DJI, GoPro или Insta360.

Dolby, Dolby Vision и символ двойного D являются товарными знаками Dolby Laboratories Licensing Corporation. Action Footage Player не связан с Dolby и не одобрен ею. Плеер сам записывает метаданные Dolby Vision с помощью открытой библиотеки dolby_vision (MIT); никакого ПО Dolby в его составе нет.
