ActionFootagePlayer for Windows carries these, unchanged except for mpv's icon (tools/make_windows_app.sh in
https://github.com/anton-belkin/ActionFootagePlayer has the exact versions and where each was downloaded from):

mpv (mpv\mpv.exe)
    GPL 2 or later (this build includes GPL parts). Source: https://github.com/mpv-player/mpv
    The Windows build: https://github.com/shinchiro/mpv-winbuild-cmake (its libraries and their sources are listed
    there), downloaded from https://sourceforge.net/projects/mpv-player-windows/ (for arm64, from its GitHub
    releases)

ffmpeg (plugins\gyroflow\ffmpeg.exe, ffprobe.exe)
    GPL 3 (licenses\ffmpeg.txt). Source: https://ffmpeg.org. The build: https://github.com/BtbN/FFmpeg-Builds
    (its gpl variant, with libplacebo and Vulkan), which lists its libraries and their sources

Python (python\)
    PSF License (licenses\Python.txt). https://www.python.org

Vulkan loader (vulkan\vulkan-1.dll, used only when the system has none)
    Apache 2.0 (licenses\Vulkan loader.txt). Source: https://github.com/KhronosGroup/Vulkan-Loader; the build:
    https://www.nuget.org/packages/Silk.NET.Vulkan.Loader.Native

NBCU LUTs (plugins\dlogm\luts\3-NBCU_HLG2SDR_DL_v1.2.cube, and plugins\dlogm\shaders\nbcu_hlg2sdr.glsl and
nbcu_pq2sdr.glsl, made from it and 5-NBCU_PQ2SDR_DL_v1.2.cube)
    Developed by NBCUniversal Media, LLC (with Cromorama and Nick Shaw), and distributed by NBCU publicly and freely,
    without warranty, on an "as is" basis, to encourage UHD Single-Master HDR-SDR production with consistent media
    exchange. https://github.com/digitaltvguy/NBCUniversal-UHD-HDR-SDR-Single-Master-Production-Workflow-Recommendation-LUTs

The gyroflow plugin's binaries (plugins\gyroflow\gyroflow-*.exe, afp-*.exe) is built from this project's vs-gyroflow/,
with Gyroflow's engine (https://github.com/gyroflow/gyroflow, GPL 3).
